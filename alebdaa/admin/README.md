# منصة إدارة حسابات الإبداع (Cloudflare Worker)

منصة خاصة لحفظ حسابات «الإبداع للمظلات» (الإيميلات، كلمات المرور، أرقام المتابعين، روابط الإدارة).

- الدخول بكلمة مرور تُفحص على سيرفر Cloudflare، ولا تُكتب في الكود.
- البيانات تُحفظ في Cloudflare KV **مشفّرة (AES-256-GCM)**، ولا تصل للمتصفح إلا بعد الدخول.
- بعد 8 محاولات دخول خاطئة يتوقف الدخول من نفس الجهاز لمدة 15 دقيقة.
- الجلسة تنتهي بعد 12 ساعة.
- الصفحة لا تظهر في محركات البحث.

## المميزات

- **الأرقام فوق:** إجمالي المتابعين، تقييم جوجل، وعدد الحسابات المكتملة.
- **تنبيهات الأمان:** كلمة مرور مكررة في أكثر من حساب، حسابات بدون تحقق بخطوتين، وكلمات مرور أقدم من 6 شهور.
- **بحث** عن أي منصة أو حساب أو إيميل.
- **الأقسام:** حسابات السوشيال، جوجل والخرائط (Business، Search Console، Analytics، Tag Manager، Google Ads، Merchant، Gmail، Apple/Bing)، الموقع والتقنية، الذكاء الاصطناعي، التصميم والمحتوى، وأخرى. كل قسم يُفتح ويُقفل.
- **جدول زي صفحة زاد:** المنصة | اسم الحساب والإيميل تحته | كلمة المرور. الحسابات اللي لها نفس الإيميل متجمّعة تحته، والحساب الإعلاني صف تحت منصته.
- تحت اسم كل منصة: عدد المتابعين ورابط لوحة إدارتها. الضغط على الاسم يفتح الحساب، والضغط على أي بيانات ينسخها.
- **كلمات المرور مخفية** وتظهر بزر «إظهار كلمات المرور».
- لكل حساب: الجوال المرتبط، المسؤول عن الحساب، حالة التحقق بخطوتين، تاريخ آخر تغيير للباسورد (يتسجّل تلقائيًا)، وملاحظة.
- **تعديل البيانات:** إضافة أي خدمة أو «خدمة أخرى» باسم تكتبه، حذف، **مولّد كلمات مرور قوية**، وتعديل تقييم جوجل ورابط صفحة الروابط.
- **مديرو الإعلانات:** روابط سريعة لـ Meta وTikTok وSnap وGoogle وX Ads.
- **حالة صفحة الروابط:** فحص رقم الواتساب وMeta Pixel وGoogle Tag وSnap Pixel وTikTok Pixel.
- **سجل الدخول:** آخر 30 محاولة دخول (ناجحة أو خاطئة) بالوقت والدولة وجزء من الـ IP، ومشفّر.
- **قفل تلقائي** بعد 15 دقيقة بدون استخدام.
- **نسخة احتياطية:** تنزيل ملف واستيراده (الملف فيه كلمات المرور بدون تشفير، احفظه بأمان).

زر «الإدارة» في صفحة الروابط يفتح: `https://alebdaa-admin.arkgulf-agency.workers.dev`
(لو اسم الـ Worker أو الـ subdomain مختلف عندك، ابعت الرابط الصحيح ونغيّره في الصفحة.)

## الطريقة 1: من لوحة Cloudflare (بدون أوامر)

1. **إنشاء مخزن البيانات:** Storage & Databases → KV → Create → الاسم: `alebdaa-admin-data`.
2. **إنشاء الـ Worker:** Workers & Pages → Create → Create Worker → الاسم: `alebdaa-admin` → Deploy.
3. **لصق الكود:** افتح الـ Worker → Edit code → امسح الكود الموجود والصق محتوى `src/index.js` كاملًا → Deploy.
4. **ربط المخزن:** Settings → Bindings → Add → KV namespace → Variable name: `DATA` → اختر `alebdaa-admin-data` → Save.
5. **إضافة الأسرار:** Settings → Variables and Secrets → Add، والنوع **Secret** لكل واحد:
   - `ADMIN_PASSWORD`: كلمة مرور الدخول للمنصة (اختر كلمة قوية، 12 حرفًا على الأقل).
   - `SECRET_KEY`: نص عشوائي طويل (40 حرفًا أو أكثر). **لا تغيّره بعد أول حفظ**، لأن البيانات مشفّرة به وستضيع لو تغيّر.
6. افتح رابط الـ Worker، وادخل بكلمة المرور، واضغط «تعديل البيانات» وأدخل الحسابات، ثم «حفظ».

## الطريقة 2: بالأوامر (Wrangler)

```bash
cd alebdaa-admin
npx wrangler login
npx wrangler kv namespace create DATA      # انسخ الـ id وحطه في wrangler.toml
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SECRET_KEY
npx wrangler deploy
```

## ملاحظات

- لتغيير كلمة مرور الدخول: غيّر `ADMIN_PASSWORD` فقط (البيانات لا تتأثر).
- `SECRET_KEY` هو مفتاح التشفير: احتفظ بنسخة منه في مكان آمن.
- المنصة لا تحفظ أي بيانات افتراضية سرية؛ الحسابات تبدأ بأسماء المستخدمين والروابط فقط، وأنت تضيف الإيميلات وكلمات المرور من داخل المنصة.
