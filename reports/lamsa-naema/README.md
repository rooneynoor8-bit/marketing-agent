# حملات لمسة ناعمة

- **بيانات العميل:** `clients/lamsa-naema.json`
- **أرقام الحملات:** `data/lamsa-naema_campaigns.csv`. حط فيه تصدير مدير الإعلانات، أو اربط حساب Meta في ملف العميل.

التقرير الأسبوعي متوقف للعميل ده (`"active": false`) لحد ما بياناته تكتمل.
