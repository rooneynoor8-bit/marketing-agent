# وكيل التسويق وتحليل السوق 🤖📈

وكيل ذكاء اصطناعي لوكالة التسويق، شغال بـ Claude (Opus 5.5). بيعمل:

- **تحليل المنافسين**: بيدور على الويب ويحلل عروضهم وأسعارهم ورسايلهم والثغرات اللي تقدر تستغلها.
- **بحث السوق والكلمات المفتاحية**: بالعربي (مصري وفصحى) والإنجليزي.
- **كتابة المحتوى**: بوستات، إعلانات، سكريبتات، إيميلات، مقالات SEO على حسب صوت البراند بتاع كل عميل.
- **تقارير أداء الحملات**: بيسحب الأرقام مباشرة من Meta Ads وGoogle Ads، أو بيقرا ملفات CSV (من أي منصة زي TikTok)، ويحسب CTR وCPC وCPA وROAS، ويقولك تكبّر إيه وتوقف إيه.

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env        # وحط مفتاح الـ API بتاعك جوه .env
streamlit run app.py         # الواجهة على المتصفح (الأسهل)
python agent.py              # أو محادثة في الشاشة السودا
python agent.py "اعمل تحليل منافسين لـ example-cafe"   # طلب واحد وخلاص
python weekly_report.py      # تقرير أسبوعي لكل العملاء
```

مفتاح الـ API بتجيبه من https://console.anthropic.com

## الواجهة (Web UI)

`streamlit run app.py` وهتفتح على http://localhost:8501 فيها:
- **المحادثة**: تختار العميل من الجنب وتكلم الوكيل.
- **التقارير**: تتصفح وتحمّل كل التقارير المحفوظة.
- **بيانات الحملات**: ترفع ملفات CSV.
- **العملاء**: تضيف عميل جديد أو تعدّل بياناته.

## التقرير الأسبوعي الأوتوماتيك

`python weekly_report.py` بيعدّي على كل العملاء، ولكل عميل بيعمل تقرير بالعامية المصرية فيه:
- أخبار المنافسين والسوق في آخر 7 أيام (من الإنترنت ومع ذكر المصادر).
- أداء الحملات: من Meta/Google لو الحسابات مربوطة، أو من آخر ملف CSV للعميل.
- توصيات للأسبوع الجاي.

التقرير بيتحفظ في `reports/<العميل>/`. ولعميل واحد بس: `python weekly_report.py example-cafe`

**جدولته كل أحد الساعة 8 الصبح:**
- **Linux/Mac**: شغّل `crontab -e` وضيف السطر ده (عدّل المسارات):
  ```
  0 8 * * 0 cd /path/to/marketing-agent && /path/to/python weekly_report.py >> reports/cron.log 2>&1
  ```
- **Windows**: افتح Task Scheduler ← Create Basic Task ← Weekly ← Sunday 8:00 ← Start a program.
  - في Program: مسار `python.exe`.
  - في Arguments: `weekly_report.py`.
  - في Start in: فولدر المشروع.

## ربط حسابات الإعلانات

ضيف رقم الحساب في ملف العميل (من تبويب «العملاء» أو بالكلام مع الوكيل):
```json
"meta_ad_account_id": "1234567890",
"google_ads_customer_id": "123-456-7890"
```

**Meta (فيسبوك وانستجرام):**
1. في [Business Settings](https://business.facebook.com/settings) ← Users ← System Users اعمل System User.
2. اديله صلاحية على حسابات الإعلانات بتاعة العملاء.
3. اعمل Generate Token بصلاحية `ads_read`.
4. حط التوكن في `.env` في `META_ACCESS_TOKEN`.

**Google Ads:**
1. `pip install google-ads`.
2. هتحتاج Developer Token من حساب الـ MCC (Tools ← API Center).
3. وهتحتاج OAuth Client ID/Secret من Google Cloud Console.
4. وهتحتاج Refresh Token: تطلّعه بسكريبت `generate_user_credentials.py` من مكتبة google-ads.
5. حطهم كلهم في `.env`، ومعاهم `GOOGLE_ADS_LOGIN_CUSTOMER_ID` (رقم الـ MCC).

لو مش عاوز تربط، الوكيل هيكمّل عادي بملفات CSV.

## إزاي تنظم الشغل

| الفولدر | فيه إيه |
|---|---|
| `clients/` | ملف JSON لكل عميل (المجال، السوق، الجمهور، المنافسين، صوت البراند، الأهداف، الميزانية). الوكيل بيقراه قبل أي شغل، وتقدر تخليه يضيف عميل جديد بالكلام عادي. |
| `data/` | حط هنا ملفات CSV اللي بتصدّرها من مدير الإعلانات. |
| `reports/` | الوكيل بيحفظ التقارير والتحليلات هنا، فولدر لكل عميل. |

## أمثلة على طلبات

- `ضيف عميل جديد: عيادة أسنان في المعادي، موقعها ...، ميزانيتها 25 ألف في الشهر`
- `اعمل تحليل منافسين كامل لـ example-cafe وقارنهم ببعض`
- `طلعلي 30 كلمة مفتاحية لعيادة أسنان في القاهرة مع نية البحث`
- `اكتب 10 بوستات انستجرام لـ example-cafe للأسبوع الجاي`
- `حلل ملف example-cafe_meta_sept.csv واعملي تقرير أداء للعميل`

## ملفات الكود

- `agent.py`: الوكيل نفسه (التعليمات، أدوات البحث على الويب، حلقة المحادثة).
- `tools.py`: الأدوات المحلية (ملفات العملاء، تحليل الـ CSV، حفظ التقارير). أي أداة جديدة تضيفها هنا بـ `@beta_tool` وتحطها في `ALL_TOOLS`.
- `ad_platforms.py`: سحب الأرقام من Meta Ads وGoogle Ads.
- `app.py`: الواجهة.
- `weekly_report.py`: التقرير الأسبوعي.
